# Austria annotation preparation — first mapping pass

Status: preparation complete for initial review; independent event annotation has not begun.

## Verified work

- The 28 registered recordings have 28 distinct source fingerprints. This rules out byte-identical files, not repeated footage or shared bouts.
- A local coordinator catalogue contains 84 decoded and visually inspected samples, three per recording. Requested positions were start, midpoint and 95% of estimated duration. One 95% seek returned no frame; that recording uses an 80% fallback, with the failed attempt retained in the manifest.
- Estimated file durations total 9,848.015 seconds (164.1 minutes). These are metadata-derived durations, not unique active-play time or verified complete-bout coverage.
- Ten recordings have readable numeric application match labels in the inspected samples. These are provisional observations, not authoritative bout identities.
- Two provisional multi-recording groups were identified from displayed match/round labels. They are prioritized for identity reconciliation because their labels are readable, not because of detector performance or event yield.
- Sampled layouts comprise 16 recordings with two camera panes, 11 with one, and one largely obscured by an application window. Camera synchronization and intervening changes remain unverified.
- A separate reviewer guide and empty event/coverage intake tables were prepared. The coordinator's visual material contains model outputs and is excluded from the independent reviewer packet.

## Evidence limitations

The samples show model overlays, cropped identity fields, placeholder identifiers, very short recordings, application-window obstruction and round labels unchanged across long recordings. Application labels cannot establish complete rounds. Three samples per file cannot establish continuous coverage, replay boundaries, temporal overlap, the number of distinct bouts or the number of reference events.

No canonical bout clusters or final round boundaries were assigned. No annotation windows were released. Empty reference tables are unpopulated drafts, not evidence of zero events. The recording used for development and every linked bout remain excluded from any eventual held-out test; unresolved linkage prevents final test allocation.

## Next evidence work

Reconcile displayed identities against authoritative bout records and continuous footage. Record gaps, rest periods, repeated actions and duplicate views. Obtain unoverlaid source footage or validate a viewing procedure over each full annotation window that removes model cues without obscuring contact evidence. Fix the event definition and ambiguity policy, assign independent qualified reviewers, and preserve their separate first passes and adjudication decisions.
