# Statistical Analysis Plan

## Objective
Evaluate FST/FST 2.0 as human-in-the-loop video-review decision support under real competition evidence, with special attention to performance degradation and appropriate human deferral under uncertainty.

## Analysis populations
1. **Independent event benchmark** — all independently enumerated reference events in the frozen evaluation set.
2. **Frozen model predictions** — all FST/FST 2.0 predictions generated without reference-label access.
3. **Matched-event table** — deterministic one-to-one event matching using a declared temporal tolerance and class rule.
4. **Candidate-annotation audit set** — the separately released 545-record canonical candidate table. This is descriptive/provenance evidence and is not substituted for the independent event benchmark.

## Primary endpoint
Event-level F1 for head-kick detection on the independent evaluation population, accompanied by TP, FP, FN, precision and recall. F1 is not reported until false negatives are independently observable.

## Secondary endpoints
- turning vs non-turning class performance;
- temporal localization error among matched events (median, IQR, distribution);
- performance by visibility/occlusion, contact quality and difficulty;
- decision-review latency under a comparable baseline and AI-assisted workflow;
- human agreement/acceptance as a separate user-study endpoint.

## Uncertainty/selective prediction
Use only a numerical uncertainty/evidence value generated by the frozen FST implementation. Human annotation confidence is not a model uncertainty score.

For threshold tau, report:
- coverage: fraction of eligible cases retained for AI-supported recommendation;
- selective risk: declared error among retained cases;
- risk-coverage curve;
- area under the risk-coverage curve where meaningful;
- risk at prespecified coverage levels and/or coverage at prespecified risk levels;
- enrichment of difficult/occluded/ambiguous cases among deferred cases.

Any threshold used for a headline test result must be fixed using development/validation data, not selected on the final test population.

## Dependence and confidence intervals
Clip/event observations from the same bout are not assumed independent. Principal intervals are therefore obtained by bout-level cluster bootstrap. If athlete identity is available in a releasable form, athlete-level sensitivity analysis should also be considered.

Report point estimates with 95% intervals where defensible. Avoid pseudo-replication from treating every frame or clip as an independent tournament-level observation.

## Event matching
The primary analysis uses deterministic one-to-one temporal matching implemented in `match_events.py`. The temporal tolerance must be declared in the manuscript. Sensitivity analysis should repeat the evaluation at at least two additional defensible tolerances.

Class-sensitive evaluation uses `class-mode=exact`; temporal-detection sensitivity analysis may use `class-mode=ignore`.

## Latency
Prefer paired or otherwise directly comparable review observations. Define start/end events identically. Report n, median, IQR, mean/SD when useful, absolute difference and relative reduction. Do not mix computational inference latency with end-to-end human review latency.

## Human study
For trust/acceptance, report participant population, N, exact question/construct, response scale and distribution. A percentage such as 93% is not sufficient without this context. Referee and coach outcomes are reported separately.

## Missing and ambiguous reference cases
Ambiguous reference cases are retained with an explicit flag. Primary analysis should use a prespecified adjudication rule; sensitivity analysis should evaluate exclusion or deferral of ambiguous references rather than silently forcing a label.

## Multiple comparisons
Contextual subgroup analyses are secondary/exploratory unless prespecified. Emphasize effect sizes and uncertainty intervals rather than a large collection of uncorrected p-values.

## Negative results
Failure of uncertainty to stratify error, or performance degradation under occlusion, is reported rather than hidden. The objective is reliable decision support, not maximization of a single headline metric.
