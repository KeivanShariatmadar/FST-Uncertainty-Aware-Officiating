# Intellectual Property and Licensing Boundary

## Purpose

This repository is intended to support scientific transparency for the SSAC research submission. Its public visibility does not, by itself, grant a license to every item discussed by the research.

## FST implementation

Unless explicitly stated for a particular file, no license is granted here to proprietary FST.ai implementation assets, including:

- operational or production source code;
- trained production models or model weights;
- non-public architecture and system-integration details;
- deployment configurations and infrastructure;
- credentials or security information;
- confidential datasets or logs;
- protected algorithms, know-how, or other background intellectual property.

## Research documentation

Files authored specifically for this repository are made publicly readable for scientific review. A separate reuse license should only be attached after the authors have confirmed ownership and agreed the intended licensing scope. The repository intentionally does not apply a blanket software license at Stage 1.

## Third-party material

No rights are granted to third-party competition video, broadcasts, athlete or official likenesses, event/federation material, trademarks, or other content owned or controlled by third parties. Such material must not be assumed to be reusable because it is referenced by the research.

## Future released code or data

If reproduction scripts or derived datasets are later released, each releasable component will carry its own explicit license or terms. A software license will apply only to software covered by that license; a data license or data-use statement will apply only to the identified data artifact.

## No implied transfer

Publication of scientific descriptions, metrics, citations, or evaluation artifacts does not transfer ownership of FST.ai or any associated background intellectual property.
