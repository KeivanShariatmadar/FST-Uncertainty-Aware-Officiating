# Intellectual Property and Licensing Boundary

## Purpose
This repository supports scientific transparency for the SSAC27 FST.ai / FST.ai 2.0 officiating submission. Public visibility does not, by itself, grant a license to every item discussed by the research.

## FST implementation
Unless explicitly stated for a particular file, no license is granted here to private/proprietary FST.ai implementation assets, including:
- operational or production source code;
- trained production models or weights;
- non-public architecture/system-integration details;
- deployment configurations/infrastructure;
- credentials/security information;
- confidential datasets/logs;
- protected algorithms, know-how or other background intellectual property.

The uploaded FST competition-platform package used for implementation audit is not automatically part of this public repository.

## Currently public research artifacts
The repository currently exposes:
- research/evaluation documentation;
- executable evaluation and audit scripts;
- de-identified candidate-level annotation data;
- derived audit summaries and audit decisions;
- bibliographic/submission material.

These files are publicly readable for scientific review. The repository currently has **no blanket reuse license** and `CITATION.cff` states `NOASSERTION`.

## Licensing decision still required
The authors have expressed an intention to permit public research use while protecting commercial exploitation of FST. That intended boundary must be reconciled with the exact SSAC open-source requirement before a legal license is attached.

No license is imposed automatically here because selecting a license changes legal reuse rights. When a licensing decision is finalized, software and data should be licensed deliberately and, if necessary, separately.

## Third-party material
No rights are granted to third-party competition video, broadcasts, athlete or official likenesses, event/federation material, trademarks or other third-party-controlled content. Such material must not be assumed reusable merely because it is referenced by the research.

## Component-specific licensing
A future software license applies only to the software files it covers. A data license/data-use statement applies only to identified data artifacts. Neither should be interpreted as licensing private FST implementation assets or third-party footage.

## No implied transfer
Publication of scientific descriptions, metrics, citations, evaluation artifacts or de-identified derived data does not transfer ownership of FST.ai or associated background intellectual property.
