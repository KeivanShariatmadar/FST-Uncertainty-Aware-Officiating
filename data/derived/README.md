# Derived Evaluation Data

This directory is intentionally empty at Stage 1.

Derived evaluation files will be added only after:
1. provenance verification;
2. confirmation of the relevant sample and denominator;
3. privacy and third-party-rights review;
4. verification that release does not expose proprietary implementation information; and
5. consistency checks against the SSAC manuscript.

No placeholder or synthetic file in this directory should be used to support an empirical claim.
