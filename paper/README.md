# SSAC Submission Materials

This directory contains public materials associated with the SSAC27 submission:

**Uncertainty-Aware AI-Assisted Video Review for Faster and More Reliable Officiating in Competitive Taekwondo**

Authors: Keivan Shariatmadar, Ahmad Osman, and Ramin Rey.

`SSAC27_FST_Competition_Abstract_Final.pdf` is the abstract prepared for the competition submission.

The SSAC paper is a focused FST.ai / FST.ai 2.0 officiating study. Broader systems and projects outside this research scope are intentionally excluded.
