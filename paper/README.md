# SSAC27 Submission Materials

This directory contains public materials associated with the SSAC27 research submission:

**Uncertainty-Aware AI-Assisted Video Review for Faster and More Reliable Officiating in Competitive Taekwondo**

Authors: Keivan Shariatmadar, Ahmad Osman, and Ramin Rey.

## Files
- `SSAC27_FST_Competition_Abstract_Final.pdf` — the previously prepared PDF submission artifact.
- `SSAC27_ABSTRACT_EVIDENCE_SAFE_DRAFT.md` — a 375-word evidence-safe revision produced after auditing the championship-derived annotations.
- `ABSTRACT_CLAIM_MAP.md` — sentence/claim-to-evidence map for the evidence-safe draft.
- `SSAC27_SUBMISSION_READINESS.md` — current competition requirements and evidence-readiness checklist.

The PDF is preserved for provenance and is not silently overwritten. The evidence-safe Markdown draft is the current conservative text until all headline FST/FST 2.0 pilot numbers have been reconciled against their source observations.

## Scope
The SSAC paper is a focused FST.ai / FST.ai 2.0 officiating study. APEX, Digital TA, WT-SCIP/SCIP, SILs and other projects are intentionally excluded.
