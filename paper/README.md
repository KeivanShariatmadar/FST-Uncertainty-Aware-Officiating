# SSAC27 Submission Materials

This directory contains public materials associated with the SSAC27 research submission:

**When Should AI Defer? An Evidence Audit of AI-Assisted Video Review in Competitive Taekwondo**

Authors: Keivan Shariatmadar, Ahmad Osman, and Ramin Rey.

## Files
- `SSAC27_FST_Competition_Abstract_Final.pdf` — the previously prepared PDF submission artifact.
- `SSAC27_ABSTRACT_EVIDENCE_SAFE_DRAFT.md` — preserved conservative evidence-safe draft.
- `SSAC27_ABSTRACT_FINAL_CANDIDATE.md` — preserved pre-promotion final candidate.
- `SSAC27_ABSTRACT_FINAL.md` — authoritative scientifically polished abstract submission text.
- `SSAC27_ABSTRACT_FINAL_POLISHED.md` — preserved polished snapshot used to promote the authoritative final.
- `SSAC27_FULL_PAPER_CURRENT_EVIDENCE.md` — preserved current-evidence manuscript snapshot.
- `SSAC27_FULL_PAPER_MASTER.md` — authoritative scientifically polished master full-paper manuscript.
- `SSAC27_FULL_PAPER_FINAL_POLISHED.md` — preserved polished snapshot used to promote the master.
- `SSAC27_SUBMISSION_COPY_PASTE.txt` — plain-text abstract package for direct submission-form entry.
- `SSAC27_FINAL_SUBMISSION_CHECKLIST.md` — final abstract-stage and full-paper upgrade checklist.
- `FINAL_SCIENTIFIC_REVIEW.md` — final judge-level scientific review and residual-risk memo.
- `ABSTRACT_CLAIM_MAP.md` — sentence/claim-to-evidence map for the evidence-safe draft.
- `SSAC27_SUBMISSION_READINESS.md` — current competition requirements and evidence-readiness checklist.

The previously prepared PDF is preserved for provenance and is not silently overwritten. The current abstract and manuscript use the narrower evidence-audit title to match the empirical scope exactly. The current submission text is `SSAC27_ABSTRACT_FINAL.md`; the authoritative full-paper manuscript is `SSAC27_FULL_PAPER_MASTER.md`. Prior-public FST/FST 2.0 headline numbers remain quarantined until their source observations are reconciled.

## Scope
The SSAC paper is a focused FST.ai / FST.ai 2.0 officiating study. APEX, Digital TA, WT-SCIP/SCIP, SILs and other projects are intentionally excluded.
