# When Should AI Defer? Uncertainty-Aware Video Review for Human-in-the-Loop Officiating in Competitive Taekwondo

## Introduction
Video review in Taekwondo must resolve high-speed scoring actions from imperfect visual evidence, often under occlusion, rapid body rotation, and limited camera perspective. Accuracy alone is therefore an incomplete objective for AI-assisted officiating: a useful system should also identify when evidence is too weak for a confident recommendation. We evaluate FST.ai as a human-in-the-loop review framework and ask what can be concluded from its championship-derived candidate evidence without conflating human annotation confidence with model epistemic uncertainty.

## Methods
We audited 546 FST candidate clips from 74 recorded match identifiers. Each candidate had a human validation label (True Positive or False Positive), human confidence, difficulty, kick type, contact quality, and row-aligned visibility. Raw records were preserved; one exact duplicate match/clip entry was excluded from the canonical population, and two identifiers documented as the same bout were treated as one clustering unit. We report candidate-confirmation statistics with a delete-one-bout cluster jackknife interval and quantify dependence among annotation fields. Because the candidate table does not independently enumerate missed true events, recall and F1 are not estimated. A separate evaluation protocol requires future model uncertainty analysis to use numerical uncertainty generated by the frozen FST implementation and to evaluate selective prediction through risk-coverage.

## Results
The canonical population contains 545 candidate clips: 449 human-validated true events and 96 false candidates, yielding an 82.39% candidate-confirmation rate (bout-cluster jackknife 95% CI: 81.16%–83.61%). The audit revealed unusually strong annotation dependence: 535 of 546 raw records (97.99%) fall into four repeated joint patterns. Of 222 partially occluded candidates, 126 are TP-labelled and 96 FP-labelled, a descriptive candidate-confirmation fraction of 56.76%. All 96 FP-labelled candidates share the same Medium-confidence, Hard, uncertain-event, uncertain-contact, partial-occlusion annotation pattern. This concentrates the observed false candidates in difficult visual evidence, but the structural coupling prevents these human fields from being interpreted as independent uncertainty calibration.

## Conclusion
For AI-assisted officiating, the relevant question is not only whether the model can classify an action, but whether it knows when to defer. The audit establishes a reproducible evidence boundary for FST: candidate-only annotations support candidate-validation analysis, while full performance requires an independent event census that observes false negatives and frozen model outputs for risk-coverage analysis. The released de-identified data and evaluation code make this distinction auditable and preserve human authority for ambiguous cases.
